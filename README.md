Entry for the [One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/c/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) bounty on make.fun — one original line, at most 200 characters, naming a hilariously useless superpower.

> "I can read minds, but only the minds of pigeons, and they're all judging my shoes."

## How it works

`main.py` writes the single line above to `/output/entry.txt`, after a pre-check that the line is 1–200 characters and not blank. Mind-reading, turned somewhere new: the only minds on offer belong to pigeons — and the joke pays off in the last few words.

## Run

```bash
python3 main.py
```
